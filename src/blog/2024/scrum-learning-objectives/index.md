## Learning objectives of a Certified Scrum Professional Developer (CSP-D), by Scrum Alliance

### Enabling a Culture of Technical Excellence
- Technical Coaching
- Service-level agreements between teams; shared Definition of Done

### Catalyzing High-Performing Technology Organizations
- Various architectural patterns: Hexagonal architecture, SOLID, event sourcing
- Strategies to update legacy codebases
- Set up automated continuous integration pipeline
- Different testing practices

### Facilitating environments for a shared understanding
- Setting up developer communities of practice
- Conducting collaborative design sessions
- Setting up experiments to examine the impact of product work on customers, stakeholders, and organization

### Guiding Scrum Teams to Learn and Grow
- Setting up communities of practice, training, coding dojos, group programming/design sessions

### Developing Self as an Agile Leader
- Understanding one's own value system, and relating it to the Agile Manifesto
- Understanding the importance of developer contribution to product exploration, customer discovery and experimentation
- Visual modelling techniques for a value stream (e.g. value stream mapping, kanban), with identification of imprevement opportunities
